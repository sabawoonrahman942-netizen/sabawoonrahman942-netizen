## ✨ Öne Çıkan Projeler

### 🚌 Online Otobüs Bilet Rezervasyon Sistemi (T-SQL / MS SQL Server)
Tam ölçekli ilişkisel veritabanı mimarisi projesi.  
→ Hata yönetimi (Transaction), indeksleme ve karmaşık `JOIN` mimarileri.  
→ Çok sütunlu benzersiz kısıtlamalar (Unique Constraints), dinamik görünüm (View) ve saklı yordamlar (Stored Procedures).  

### ⚡ Veritabanı Sorgu Optimizasyon Aracı (Java)
Veritabanı sorgularının çalışma sürelerini analiz eden ve optimizasyon önerileri sunan Java uygulaması.
